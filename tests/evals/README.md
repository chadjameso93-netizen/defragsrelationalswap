# DEFRAG evals

This folder holds simple fixtures and checks for product output quality.

The goal is to catch:
- jargon
- inflated language
- false certainty
- repetitive guidance
- unclear next steps
- language that feels clinical or stigmatizing

## Initial eval groups
- plain-language
- no-diagnosis
- no-false-certainty
- clear-next-step
- relationship-summary-quality

## Rule
If a response sounds smart but not useful, it should fail.
